# Stuck Protocol

Trigger: 30 minutes blocked on one task. (Set a mental flag the moment you notice you're going in circles.)

1. **Write the question precisely** in the day block, under the task: what you expected, what happened, the exact error. One paragraph. This alone resolves ~half of all blocks.
2. **One targeted search** (10 min max): the exact error message in quotes, or the precise question. Read one or two results, not twelve tabs.
3. Still blocked? **Mark the task ⚠ and move to the next task.** ⚠ tasks get fresh-eyes treatment in the Friday block — most dissolve on re-approach.
4. **Never** end a session early because of a block. Blocked on task 2 means you're now doing task 3.

## Escalation ladder for ⚠ items (Friday)

1. Re-attempt cold — fresh eyes fix most.
2. Rebuild a minimal repro in a scratch project — isolating it usually exposes it.
3. Read the relevant official docs page top to bottom (now it's targeted reading, which is allowed).
4. Still stuck after all that → it's a genuine hard spot: add to `weak-spots.md` and ask a human/community with your precisely-written question. You've earned the right to ask well.

## What this protocol protects

Momentum and the streak. The failure mode it prevents: one bad bug eats three sessions and the plan collapses. The system absorbs blocks; it doesn't stop for them.
